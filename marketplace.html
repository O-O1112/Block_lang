Official registry / v2.2.5

Extend the flow.
Keep the boundary.

Block packages are ordinary, reviewable files. The official registry publishes metadata and SHA-256 digests; the engine verifies remote files before installing them and never executes package code during installation.

Install a package after reviewing its permissions: block pkg info drawing, then block pkg install drawing --remote. The registry is maintained in GitHub source; package capabilities remain explicit and host runtimes are never bundled silently.

01 / concurrency

Octopus

Bounded native helpers for batching and concurrency-oriented workflows. The v2.2.5 starter surface is deterministic and does not create processes or threads.

nativebatchperformance
block pkg install octopus --remote

02 / web

Block Web

Safe native conventions for web documents and status handling. Network access remains a host policy decision.

nativewebapi
block pkg install block-web --remote

03 / games

Gblock:D

Deterministic state helpers for game prototypes, including clamping and alive-state checks.

nativegraphicsgame
