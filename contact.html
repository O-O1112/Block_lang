Trust / Contact

Contact and support

Use the public project channels below so questions, fixes, and release history remain visible and verifiable.

General support

For installation questions, compatibility reports, and documentation corrections, open a GitHub issue. Include the Block version, edition, operating system, and a minimal reproduction. Remove personal data before posting.

Security reports

Do not publish an exploitable vulnerability in a public issue. Use a private GitHub Security Advisory and read the security policy first.

Project identity

Block Engine is developed in the open at github.com/O-O1112/Block_lang. Release assets, checksums, source code, and change history are published there.

What not to send

Never include passwords, API tokens, private keys, certificates, financial information, or unredacted logs in issues or pull requests.
