## Documentation rules

Documentation should identify the tested version, edition, operating system, and host
runtime whenever a command or behavior depends on them. Keep planned behavior clearly
separate from shipped behavior. Do not describe a first-party example as independent
validation; use the [third-party validation process](THIRD-PARTY-VALIDATION.md) for
external reports.
