# CLI workspace and project discovery

Block can resolve relative `.blk`, `.blkl`, and `.blkp` files from the current
project and a configured workspace. See the repository guide:

- [CLI workspace guide](https://github.com/O-O1112/Block_lang/blob/main/docs/CLI-WORKSPACE.md)
- [Installation](Installation.md)
- [Syntax](Syntax.md)

Useful commands:

```powershell
block workspace set C:\Users\you\BlockProjects
block workspace show
block find hello
block project root
block project run
```
