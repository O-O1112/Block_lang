Trust / Privacy

Privacy notice

Last updated: 23 August 2026. Block Engine is an open-source, local-first programming engine and this website is a documentation and download site.

What we collect

The website does not ask you to create an account, enter a password, submit payment details, or provide source code. Cloudflare Web Analytics may collect privacy-preserving performance and page-view metrics. It is used to understand site usage and page performance, not to identify individual visitors.

Third-party services

Downloads are hosted through GitHub Releases. Fonts may be served by Google Fonts. GitHub, Google, and Cloudflare process requests under their own policies. The Block Engine website does not sell personal information or use advertising profiles.

Downloads and local execution

Block binaries run on your device and may start installed language runtimes. Review the release notes and verify SHA-256 checksums before installation. Do not run untrusted Block files.

Questions

For privacy questions, use the contact page or open a non-sensitive GitHub issue. Never post credentials, private keys, or personal data in a public issue.
